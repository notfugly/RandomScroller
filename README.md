# Compose Jetpack Joyride

An Android app that displays a scrollable feed of random images found through the Openverse API.

Built with Kotlin, Jetpack Compose, Coil, and OkHttp. The app searches using random words and preloads upcoming images.

## Getting started

1. Open the project in Android Studio.
2. Sync Gradle and run the app on an Android 7.0+ device or emulator.
3. Make sure the device has an internet connection.
